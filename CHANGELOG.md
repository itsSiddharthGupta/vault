### Added
- Initial implementation of the Vault KSP processor
- Support for generating type-safe DataStore preference wrappers
- Added `@VaultSchema` annotation for marking data classes as preference schemas
- Added `@VaultItem` annotation for marking properties as preference items
- Support for various types: String, Int, Boolean, Float, Long, Double, Set<String>
- Comprehensive documentation in README.md
- Example code demonstrating usage patterns
- Contributing guidelines
